Read this first (non-developer, theme-agnostic, ~5 minutes)
What you will do:
- Create a new snippet `snippets/ed-cro-cross-selling.liquid` and paste the code in Step 1.
- Add a new block definition to your product section's schema (Step 2).
- Render that block so it shows on the product page (Step 3).
- Create the product metafield and assign products (Steps 4 and 6).
- Add the block in the Theme Editor and save (Step 5).
How to open the code editor:
- Shopify Admin > Online Store > Themes > … > Edit code
Make a safe backup first:
- In Themes, click the … menu next to your live theme > Duplicate
Finding the right files (names vary by theme):
- Product section file (in `sections/`) is commonly:
  - `main-product.liquid` (Focal/Dawn-like)
  - or `product.liquid`, `product-template.liquid`, `product-main.liquid`
  - If you see `templates/product.json`, open it to see which section name it loads (e.g., "main": "main-product"), then open that section in `sections/`.
- Product form file is commonly:
  - `snippets/product-form.liquid` (Focal/Dawn)
  - or `snippets/main-product-form.liquid`
  - or the form is inline inside the product section; search for `{% form 'product' %}`.
Tip: Use the search box in the code editor and try: main-product, product-form, section.blocks, case block.type

          function loadResource(type, url) {
            return new Promise((resolve) => {
              if (document.querySelector(`${type === 'css' ? 'link' : 'script'}[href="${url}"], [src="${url}"]`)) {
                return resolve(); // If already loaded, resolve immediately
              }

              const element = document.createElement(type === 'css' ? 'link' : 'script');

              if (type === 'css') {
                element.rel = 'stylesheet';
                element.href = url;
              } else {
                element.src = url;

              if (type === 'css') resolve(); // Resolve immediately for CSS

        function openContent(element) {
          element.style.overflow = 'hidden';
          const height = element.scrollHeight;

          const keyframes = {
            height: ['0px', `${height}px`],
            visibility: ['hidden', 'visible'],
            opacity: element.hasAttribute('data-animate-items') ? [0, 0] : [1, 1],
          };

            duration: 500,
            direction: 'normal',
            easing: 'cubic-bezier(0.75, 0, 0.175, 1)',
            fill: 'forwards',

            element.style.overflow = 'visible';

        function closeContent(element) {
          const height = element.scrollHeight;

          element.style.overflow = 'hidden';

          const animation = element.animate(

              visibility: ['visible', 'hidden'],

            element.removeAttribute('data-open');

        function initCollapsibleToggle(scope = document) {
          const toggles = scope.querySelectorAll('.ed-collapsible-toggle');

          toggles.forEach((toggle) => {
            // Prevent re-initializing the same toggle
            if (toggle.dataset.initialized === 'true') return;

            toggle.dataset.initialized = 'true';

            const contentId = toggle.getAttribute('aria-controls');
            const content = scope.querySelector(`#${contentId}`);
            if (!content) return;

            toggle.addEventListener('click', () => {
              const isOpen = toggle.getAttribute('aria-expanded') === 'true';

              toggle.setAttribute('aria-expanded', String(!isOpen));
              toggle.classList.toggle('is-open', !isOpen);

              if (!isOpen) {
                openContent(content);
              } else {
                closeContent(content);
              }
            });
          });
        }

            const section = e.target;

Step: 3
Where to paste (themes differ):
- Preferred: `snippets/product-form.liquid` (Focal/Dawn). Paste the loop anywhere AFTER the opening `{% form 'product' %}` area renders, so the block shows near the Add to cart.
- If your theme has `snippets/main-product-form.liquid`, paste there similarly.
- If there is no product-form snippet: open your product section (from Step 2), find `{% form 'product' %}` … `{% endform %}` and paste the loop immediately AFTER the form closes so the widget shows below the main product add to cart.
- If nothing renders after adding the block in Step 5, move this render higher/lower in the section to your desired spot.

Step: 4
Create Product Metafield with below details:

How to create metafield (click-path):
- Shopify Admin > Settings > Custom data > Products > Add definition
- Name: "CRO | Up/Cross-Selling"
- Namespace and key: standard.cro_up_cross_selling
- Type: Product
- Check "List of products" (multi-select)
- Save




Step:5 
- Online Store > Themes > Customize
- Open a product page from the preview selector (top center)
- In the left sidebar, click your main product section (e.g., Product information/Main product)
- Click "Add block" and select "CRO | Cross selling"
- Adjust settings (Heading, ATC text, Layout, spacing). Save.


Step: 6
Assign products to the metafield:
- Shopify Admin > Products > open a product
- Scroll to Metafields (bottom of page)
- Find "CRO | Up/Cross-Selling"
- Select one or more products to recommend
- Save

Troubleshooting (common issues):
- Block not visible: Ensure you added the block in Customize (Step 5) and assigned metafield products (Step 6). Also add items to cart or change variant to trigger visibility on first load; or remove the "active on events" behavior by removing the bottom script in the snippet if you want always-on.
- JSON error in `{% schema %}`: You likely misplaced a comma or quote. Each block in `blocks` needs commas between them, but not after the last. Quotes must wrap all keys/strings.
- I cannot find `main-product.liquid`: Open `templates/product.json` and note the section handle under "sections" (e.g., "main": "main-product"). Then open `sections/<that-name>.liquid`.
- My theme lacks `product-form.liquid`: Paste the render loop into the section near `{% form 'product' %}` or create `snippets/product-form.liquid` and include it where the theme includes the form.
- Styling looks off: Adjust margins in the block settings. You can tweak CSS inside the snippet later if needed.
