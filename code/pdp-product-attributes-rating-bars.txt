Guide: CRO | Product Attributes — works on any Shopify theme

Total time: ~5–10 minutes. Follow the steps in order. Copy/paste the code exactly where indicated.


Step: 1 — Prerequisites (create Metaobject + Product Metafield)
Create Metaobjects & Metafields with below details:
    Metaobjects:
    Custom data > Metaobject > Add definition 
    Name: CRO | Product Attributes
    Type: cro_product_attributes

    Fields:
    Name: Name
    Type: Single line text
    Key: cro_product_attributes.name
    Description: Enter the product name. This will help you easily identify this metaobject later.
    Use this field as display name
    Required field

    Name: Heading
    Type: Single line text
    Key: cro_product_attributes.heading

    Name: Title 01
    Type: Single line text
    key: cro_product_attributes.title_01

    Name: Progress 01
    Type: Integer
    Min: 0
    Max: 100
    key: cro_product_attributes.progress_01

    Name: Attributes 01
    Type: Single line text - List of values
    key: cro_product_attributes.attributes_01

    Name: Title 02
    Type: Single line text
    key: cro_product_attributes.title_02

    Name: Progress 02
    Type: Integer
    key: cro_product_attributes.progress_02

    Name: Attributes 02
    Type: Single line text - List of values
    key: cro_product_attributes.attributes_02

    Name: Title 03
    Type: Single line text
    key: cro_product_attributes.title_03

    Name: Progress 03
    Type: Integer
    key: cro_product_attributes.progress_03

    Name: Attributes 03
    Type: Single line text - List of values
    key: cro_product_attributes.attributes_03


    Metafield:
    Custom data > products > metafield > add definition:
    Name: CRO | PDP | Product attributes
    Namespace and key:  standard.cro_product_attributes
    Select type: Mixed reference
    References: CRO | Product Attributes

After creating the Metaobject definition, add at least one entry (Custom data > Metaobjects > CRO | Product Attributes > Add entry) and fill in Heading, Titles, Progress values (0–100), and Attributes. Then on any product page (Products > choose a product), set the Metafield “CRO | PDP | Product attributes” to that entry and Save.

Step: 3 — Add the block to your product section schema
Where to paste:
    Online Store > Themes > Edit code
    Find your product’s main section file:
        If your theme uses templates/product.json (Online Store 2.0): open it, find the section used for the main product (e.g., type: "main-product" or similar), then open that section under Sections (e.g., sections/main-product.liquid).
        If your theme uses product.liquid: open it, find the {% section '...' %} that renders the product, then open that section under Sections.
    Scroll to the bottom of the section file and locate:
        {% schema %}
        { ... }
        {% endschema %}
    Inside the JSON, find "blocks": [ ... ] and paste the object below as a new entry in that array (keep commas between objects).

Step: 4 — Render the block in the product section’s block loop
Where to paste:
    In the same section (or in a snippet it uses, commonly snippets/product-form.liquid), find the loop:
        {% for block in section.blocks %} ... {% endfor %}
    Inside the {% case block.type %} switch, add the branch below.
  Paste this code:
  {%- for block in section.blocks -%}
    {%- case block.type -%}
      {%- when 'cro_product_attributes' -%}
        {% render 'ed-cro-product-attributes', product: product, block: block %}
    {%- endcase -%}
  {%- endfor -%}


Step: 5 — Turn it on in Theme Editor and connect data
    Online Store > Themes > Customize > open a Product page
    In the left panel, click the main product section > Add block > CRO | Product Attributes
    Save
    If it’s empty, open the Product in admin and set the Metafield “CRO | PDP | Product attributes” to your created Metaobject entry, then Save. Refresh the preview.


Troubleshooting
    I don’t see the block in Add block:
        Ensure you pasted the block object into the section’s "blocks" array inside {% schema %} (Step 3) and saved without JSON errors (commas between blocks).
    I don’t see any content after adding the block:
        Ensure the product’s Metafield is set to a Metaobject entry (Step 1) and the render branch was added (Step 4).
    My theme uses different filenames:
        Always locate the product’s main section via templates/product.json (type) or product.liquid > {% section '...' %}.


Quick checklist
    Created Metaobject definition + one entry
    Created Product Metafield referencing the Metaobject
    Added snippet: snippets/ed-cro-product-attributes.liquid (Step 2)
    Added block object to section’s {% schema %} > "blocks" (Step 3)
    Added render branch in the block loop (Step 4)
    Enabled the block in Theme Editor and linked a Metaobject entry (Step 5)
