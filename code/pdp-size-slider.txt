Ste-4: Setup Metaobject & Metafield with below details:
Metaobjects:
Custom data > Metaobject > Add definition 
Name: CRO | PDP |  Size Slider
Type: cro_pdp_size_slider

Fields:
Name: Name
Type: Single line text
Key: cro_pdp_size_slider.name
Description: Enter the product name. This will help you easily identify this metaobject later.
Use this field as display name
Required field

Name: Heading
Type: Single line text
Key: cro_pdp_size_slider.heading

Name: Labels
Type: Single line text
key: cro_pdp_size_slider.labels
List of Values
Required field


Name: Scale position
Type: Integer
key: cro_pdp_size_slider.scale_position
Description: Percentage value 0–100%
Min: 0
Max: 100
Required field



Metafield:
Custom data > products > metafield > add definition:
Name: CRO | Size Slider
Namespace and key:  standard.cro_size_slider
Select type: Mixed reference
References: CRO | PDP | Size Slider
