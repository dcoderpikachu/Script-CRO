CRO | Cart | Stock Availability — Setup Guide (No‑Code Friendly)

What this adds
A stock availability meter on each cart item showing remaining stock percentage.
Two layouts (Default and Classic) with customizable colors and text in Theme settings.
Uses a Variant metafield "Original Quantity" to calculate percentages (defaults to 100 when empty).

Before you start
Duplicate your live theme: Online Store → Themes → … (Actions) → Duplicate. Work on the copy.
You’ll use Edit code for one snippet and paste one settings block. The rest is point‑and‑click.

Step 1: Add the snippet
In the theme code editor: Snippets → Add a new snippet → name it exactly: ed_cro_stock_availability
Paste EVERYTHING below into that new snippet and Save.

Step 3: Create the Variant Metafield (no code)
Shopify Admin → Settings → Custom data → Variants → Add definition:
  Name: CRO | Original Quantity
  Namespace and key: standard.cro_original_quantity
  Type: Integer
  Description: Original quantity
  Minimum: 0
Save.


Step 4: Insert the snippet into your cart (works on any theme)
You’ll paste a short line inside the cart items loop. Exact files vary by theme.
Mini cart / Cart drawer (look for any of these):
 snippets/cart-drawer-items.liquid
 snippets/cart-drawer.liquid
 sections/cart-drawer.liquid
 snippets/mini-cart.liquid

Main cart page (look for any of these):
 sections/main-cart-items.liquid
 sections/main-cart.liquid
 templates/cart.liquid
 snippets/cart-line-item.liquid

Inside the file you find, locate the loop that renders items (often 'for line_item in cart.items' or 'for item in cart.items'). Paste this line where each product is displayed (near the product title/quantity), preferably before the closing of that item block.

{%- if settings.show_cro_stock_availability -%}
  {% render 'ed_cro_stock_availability', line_item: line_item %}  
{%- endif -%}

If your loop variable is 'item' (not 'line_item'), use:

{%- if settings.show_cro_stock_availability -%}
  {% render 'ed_cro_stock_availability', line_item: item %}  
{%- endif -%}

Tips to find the right spot
 Use the code editor search for: cart.items, cart-drawer, line-item, mini-cart.
 In table-based carts, look for a cell like: <td class="line-item__product">.
 Ensure you paste INSIDE the loop, so the snippet runs once per cart item.

Step 5: Customize the look (no code)
 Online Store → Customize → Theme settings or Cart settings:
   Toggle "Show Stock Availability".
   Choose layout (Default or Classic).
   Adjust colors and text to match your brand.
 Save.

Step 6: Test
 Preview the theme.
 Add a product with tracked inventory to the cart.
 Open the mini cart and the main cart page; confirm the bar and text render.
 Check on mobile.

Troubleshooting
 Nothing shows:
   The render line must be inside the items loop ('for … in cart.items').
   Verify the loop variable name matches ('line_item' vs 'item').
   Turn on "Show Stock Availability" in Theme settings.
 Bar shows 0%:
   Ensure the variant’s inventory tracking is enabled (Product → Variant → Track quantity).
   If you set the metafield, ensure it’s greater than 0.
 Error saving settings_schema.json:
   Usually a comma error. If you pasted at the end of a list, add a comma BEFORE your block and avoid a trailing comma at the very end of the file.
 EU number formatting:
   The snippet formats 1,000–9,999 as "1,234". Change the comma to a dot in the Number formatter section if desired.

Uninstall
 Remove the render lines you added in cart files.
 Delete the snippet ed_cro_stock_availability.
 (Optional) Remove the settings block from config/settings_schema.json.
 (Optional) Delete the metafield definition in Settings → Custom data → Variants.
