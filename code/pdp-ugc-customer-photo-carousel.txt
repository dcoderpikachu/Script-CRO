Step: 0
Make a safe copy of your theme (Recommended)
1) In Shopify admin go to Online Store > Themes.
2) Click the three dots (⋯) next to your live theme > Duplicate. Work on the copy.
3) When you’re done, preview the copy to test. Publish only after verifying.

Step: 1
Find your product section file (any theme) and add the block type
Do this:
1) Open templates/product.json. Note the main section type (for example: "main-product", "product-template", or "product").
2) In sections/, open the file whose name matches that type (e.g., sections/main-product.liquid).
If templates/product.json does not exist, open sections/main-product.liquid or sections/product-template.liquid or sections/product.liquid — pick whichever exists.

Add the block type inside {% schema %}:
- In that file, find {% schema %} and {% endschema %}.
- Inside the JSON there, find "blocks": [ ... ]. If there is no blocks array, add "blocks": [] inside the top-level JSON object.
- Paste the following block object INSIDE the square brackets [ ... ] as one item. If you paste it after another item, put a comma above it.

Step: 3
Render the block (works for all themes)
In the same product section file from Step 1 (or the snippet that renders blocks), find the loop that renders blocks:
- Search for: {% for block in section.blocks %}

Then insert ONE of the following INSIDE that loop, depending on what your theme uses:

If it uses a switch/case pattern:
{% case block.type %}
  ...
  {% when 'cro_ugc_section' %}
    {% render 'cro_ugc_section', product: product, block: block %}
  ...
{% endcase %}

If it uses if/elsif conditions:
{% if block.type == 'cro_ugc_section' %}
  {% render 'cro_ugc_section', product: product, block: block %}
{% endif %}

Note: Some themes render blocks inside a snippet (common names: snippets/product-form.liquid, snippets/main-product-blocks.liquid). If you see the loop there, insert the same lines inside that snippet.

Step: 4
Add the block to your Product template (no code)
1) Online Store > Themes > Customize.
2) Open your Product template.
3) In the left sidebar, click your main Product section.
4) Click Add block and select "CRO | UGC Section". Drag to the position you want. Save.
