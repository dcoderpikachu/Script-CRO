Universal setup guide — CRO | PDP | Passform (theme-agnostic, OS 2.0‑first)

Prerequisites
- Duplicate your live theme before editing.
- Create a product metafield (Admin → Settings → Custom data → Products):
  - Name: CRO | PDP | Passform
  - Namespace and key: standard.cro_pdp_passform
  - Type: Single line text

Step: 3 Render the block in the section
Most OS 2.0 product sections iterate blocks. Add a case:
{% for block in section.blocks %}
  {% case block.type %}
    {% when 'cro_pdp_passform' %}
      {% render 'cro_pdp_passform', product: product, block: block, section: section %}
  {% endcase %}
{% endfor %}

If your theme uses if/elsif:

{% for block in section.blocks %}
  {% if block.type == 'cro_pdp_passform' %}
    {% render 'cro_pdp_passform', product: product, block: block, section: section %}
  {% endif %}
{% endfor %}

QA checklist
 Desktop: visible/hidden per setting; alignment correct; border optional.
 Mobile: optional full-bleed variant; overlay position correct.
 Icon: SVG overrides Image; alt text present for image.


Troubleshooting
 Not visible: ensure metafield has a value and block is added.


Uninstall notes
 Remove the block from the product section.
 Delete snippets/cro_pdp_passform.liquid.
