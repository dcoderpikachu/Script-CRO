IMPORTANT: Please complete Step: 0 before editing your theme.

Step: 0
Safety first: duplicate your theme (works for any Shopify theme)
- In Shopify admin, go to Online Store > Themes.
- On your current live theme, click ... (or Actions) > Duplicate.
- A copy appears under Theme library. Click the name to rename (e.g., "CRO setup - Draft").
- Work on the duplicate only: click Actions > Edit code.
- Use Actions > Preview on the duplicate to test changes safely.
- Publish the duplicate only after you verify everything works.

Theme-agnostic notes for finding files
- Product section file: commonly sections/main-product.liquid (may be sections/product-main.liquid, sections/product.liquid, or similar).
- Product form snippet: commonly snippets/product-form.liquid (may be snippets/main-product-form.liquid or similar).
- If unsure, in Edit code use the search bar to find "product-form", "add to cart", or "Buy buttons".

Step: 1
Go to product section file: sections/main-product.liquid (or your theme's equivalent)
Add new block for CRO | Highlight GTD

Where to paste (simple, non‑developer steps):
- In Shopify admin, open Online Store > Themes > Actions > Edit code.
- Open sections/main-product.liquid (or your product section file).
- Press Cmd+F (Ctrl+F on Windows) and search for: {% schema %}
- In the schema area, find the "blocks": [ ... ] list.
  - If you see other items inside this list, add a comma at the end of the previous item before pasting.
  - If you do not see a "blocks" list, you can create one under the schema root and paste the code below inside it.
- Now paste the code below inside the blocks list.
- Click Save.

Add the block in the Theme Editor:
- Go to Online Store > Themes > Customize.
- Open your Product template.
- In the left sidebar, select your product section and click Add block.
- Choose "CRO | Highlight GTD" and position it where you want. Click Save.

  {%- for block in section.blocks -%}
    {%- case block.type -%}
      {%- when 'cro_highlight_guarantees' -%}

  {%- endfor -%}


Final steps (Test and publish):
1. Test on the duplicate theme:
   - In Online Store > Themes, click Actions > Preview on your duplicate.
   - Open a product page and verify the highlight block appears and is styled.
2. Publish when ready:
   - When everything looks good, click Actions > Publish on the duplicate theme.

Troubleshooting:
- Block not visible: Ensure the block is added/enabled in the product section and the snippet render has been added to the product form snippet.
- Can't find where to paste: Search for {% schema %} and locate the "blocks" list; paste the code as a new item inside the list, adding a comma after the previous item if needed. Save and refresh the Theme Editor.
- JSON error when saving: Check for missing or extra commas and matching braces. Each block item should be separated by a comma, except the last one.
- Image not showing: Upload/select an image in the block settings or use the placeholder.
- Styling off: Adjust block settings (sizes, colors, positions) in the Theme Editor.
